# Mission: Cloud Run Provisioning

## Why
The user needs to make an informed architectural decision regarding which Infrastructure as Code (IaC) tool (Terraform, Pulumi, or ClickOps) to use for provisioning Google Cloud Run environments and CI/CD pipelines in this project.

## Success looks like
- The user can articulate the core differences between Terraform, Pulumi, and ClickOps.
- The user can confidently answer the wayfinder grilling questions regarding the IaC tool, environment isolation, and Workload Identity Federation setup.

## Constraints
- The user is already working within a TypeScript/Fastify/Typebox application stack.
- Needs to be highly relevant to setting up a new project's infrastructure.

## Out of scope
- Deep dives into advanced Terraform or Pulumi features not needed for basic Cloud Run deployment.
- CI/CD platforms other than GitHub Actions.
