# INC-IO Engine

The core rules engine and document management system that validates payloads, resolves identities, and orchestrates activities.

## Language

**RecordType**:
The structural definition for a class of managed documents.
_Avoid_: Business entity, generic schema

**RecordSchema**:
The subset of a `RecordType` defining the shape of the data payload.

**FormSchema**:
The presentation-ready definition containing the `RecordSchema` and UI configuration needed by the frontend.
_Avoid_: raw schema, recordUiConfig

**Record**:
A validated, immutable instance perfectly satisfying a `RecordType`.
_Avoid_: Payload, document

**Activity**:
A declarative instruction generated by the core domain to be executed by a driven adapter.
_Avoid_: Side-effect, action

**ActivityOutput**:
A generic patch or effect produced by an executed Activity, containing fields like `recordDataPatch`, `files`, or `contextVariables` that the engine merges into the workflow context.
_Avoid_: Execution result, side-channel mutation

**FileLocator**:
A defined object used to identify a file or folder across any storage provider, standardizing properties like `name` and `parentName` to assist with disambiguation where full paths aren't available (like Google Drive).
_Avoid_: FileReference, DriveFileResult

**RecordField**:
A definition of a pure data property expected within a `Record`.
_Avoid_: Property, variable

**CalculatedField**:
A read-only field derived dynamically from the base payload. Cannot reference other calculated fields or identity properties.
_Avoid_: Derived field, formula field

**Identity**:
Templates generating unique identifiers (e.g., `id`, `idRecord`, `idGroup`) based on the payload, used in workflows and activities.

**LookupField**:
A `RecordField` that links to and validates against predefined option tuples, enriched to provide both machine-friendly identifiers and human-friendly display names.
_Avoid_: ListField

**StorageContext**:
A configuration block defining storage identifiers and paths evaluated against the enriched `Record` payload.
_Avoid_: StorageConfig, StorageMapping, DriveContext

**Manifest**:
The root registry of available `RecordType` schemas and `AppConfiguration`.

**AppConfiguration**:
Domain and administrative defaults that govern application behavior, distinct from environment-bound secrets.

**Workspace Addon**:
The primary user interface, acting as a driving adapter to the core engine.
