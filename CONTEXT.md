# INC-IO Engine

The core rules engine and document management system that validates payloads, resolves identities, and orchestrates activities.

## Language

**DocumentType**:
The structural definition for a class of managed documents.
_Avoid_: Business entity, generic schema, recordType

**DocumentSchema**:
The subset of a `DocumentType` defining the shape of the data payload.
_Avoid_: recordSchema

**DocumentUiSchema**:
A highly condensed, abstract blueprint that maps `DocumentSchema` fields to UI concepts (widgets, labels, reactive behaviors). Separated from the core domain.
_Avoid_: documentUiConfig, FormSchema

**DocumentParseSchema**:
The declarative blueprint within a `DocumentType` defining how `Document` data fields are extracted from a `SourceContext`. Separated from the core domain.
_Avoid_: documentParseConfig, ParseRules, ExtractionSchema

**DocumentFormSchema**:
The declarative blueprint within a `DocumentType` mapping structured document form field names (such as PDF AcroForm widgets or Google Docs form fields), Handlebars field templates, option value overrides, and date formats to `Document` fields; all declared fields are readable by default while write operations stamp only fields explicitly marked writable. Separated from the core domain.
_Avoid_: PdfFormSchema, PdfConfig, AcroFormMapping, StampSchema

**DocumentLogSchema**:
The declarative blueprint within a `DocumentType` defining how that `DocumentType` binds to a `DocumentSpace`'s `DocumentLog` — mapping `Document` fields, calculated values, identities, and filed links to log rows, and binding `LookupField` option sources to `DocumentLog` option tables. Separated from the core domain.
_Avoid_: logConfig, sheetConfig, loggingSchema, DocumentLogConfig

**DocumentSpaceType**:
The structural definition for a category of storage containers (e.g., Projects or Proposals), specifying which `DocumentType`s are allowed and how `DocumentSpace` instances are fetched from storage.
_Avoid_: ContainerType, SpaceCategory

**DocumentSpace**:
A pre-existing storage container instance (such as a Google Shared Drive or root folder) belonging to a `DocumentSpaceType`, identified by a canonical ID, display name, and `abstractStorageId`. Users select an existing `DocumentSpace` when filing a `Document`; new `DocumentSpace`s cannot be created through the filing flow.
_Avoid_: Workspace, FolderContainer, TargetDrive

**SpaceUiSchema**:
The abstract blueprint mapping `DocumentSpaceType` attributes to UI concepts.
_Avoid_: spaceUiConfig

**Document**:
A validated, immutable instance perfectly satisfying a `DocumentType`.
_Avoid_: Payload, record

**DocumentLog**:
A `DocumentSpace`-scoped structured ledger of persisted `Document` instances across historical actions and revisions, independent of its underlying storage engine.
_Avoid_: Log Sheet, Log File, Tracking Sheet, Log

**DocumentTemplate**:
A logical template artifact referenced by a `DocumentType` workflow and resolved outside source control.
_Avoid_: TemplateFile, CoverSheetId, HardcodedTemplate

**Activity**:
A declarative instruction generated by the core domain to be executed by a driven adapter. Must only contain serializable domain data.
_Avoid_: Side-effect, action

**ActivityOutput**:
A generic patch or effect produced by an executed Activity, containing fields like `documentDataPatch` or `contextVariables` that the engine merges into the workflow context.
_Avoid_: Execution result, side-channel mutation

**ActivityExecutionContext**:
The immutable pipeline state folded across a workflow's `Activity` sequence (`document`, `files`, `stepOutputs`, `contextVariables`), enabling downstream `Activity` steps to consume upstream `FileLocator`s and variables without mutating `Document.data`.
_Avoid_: PipelineState, WorkflowState, ExecutionBag

**SourceFile**:
A descriptor representing an input file or folder to be processed by an `Activity`, independent of its origin (such as a selected Google Drive item, a Google Drive file or folder URL, an email attachment, or a generated email PDF). A `DocumentType` can restrict inputs to files only, rejecting folders.
_Avoid_: SelectedItem, Attachment, RawFile

**SourceContext**:
A normalized representation of a source's metadata and structured content (such as a Gmail message/thread, Google Drive file metadata, PDF form fields, or Google Docs form fields) inspected by `SourceParser` to pre-populate UI state before filing.
_Avoid_: ParseInput, RawEventContext, SourcePayload

**FileLocator**:
An infrastructure-agnostic output pointer to a stored file produced by an `Activity` and returned in `ActivityOutput.files`.
_Avoid_: DriveFileResult, FileMetadata

**DocumentField**:
A definition of a pure data property expected within a `Document`.
_Avoid_: Property, variable, recordField

**CalculatedField**:
A read-only field derived dynamically from the base payload. Cannot reference other calculated fields or identity properties.
_Avoid_: Derived field, formula field

**Identity**:
Templates generating unique identifiers (e.g., `id`, `idDocument`, `idGroup`) based on the payload, used in workflows and activities.

**LookupField**:
A `DocumentField` that links to static or dynamically sourced option tuples (and optionally accepts new user-entered values when `allowUserInput` is enabled), enriched to provide both machine-friendly identifiers and human-friendly display names.
_Avoid_: ListField

**LinkedField**:
A `DocumentField` whose default value is derived from a property of a sibling `LookupField` option tuple, automatically locking in the UI when a known option with a non-blank property value is selected and unlocking for custom user input when the lookup value is custom, blank, or has a blank derived property.
_Avoid_: DependentField, AutoFillField

**StorageContext**:
A configuration block defining storage identifiers and paths evaluated against the enriched `Document` payload.
_Avoid_: StorageConfig, StorageMapping, DriveContext

**Manifest**:
The root registry of available `DocumentType` schemas and `AppConfiguration`.

**AppConfiguration**:
Domain and administrative defaults that govern application behavior, distinct from environment-bound secrets.

**Workspace Addon**:
The primary user interface, acting as a driving adapter to the core engine.

**UiProcessManager**:
The command/write model orchestrator in the CQRS UI pattern. Responsible for evaluating UI state and events, decomposing information to pass to domain features via ports, and translating human-readable display names (both `DocumentType` and `DocumentSpace`) into technical keys/identifiers for backend processing. Does not build UI structures.
_Avoid_: UiController, StateManager

**SchemaDrivenUi**:
The read-only model orchestrator in the CQRS UI pattern. A generic engine that receives clean view state from the `UiProcessManager` and constructs abstract `UiView`s. Responsible for fetching or resolving display names for rendering.

**UiBlock**:
A pure presenter function inside `SchemaDrivenUi`. Maps data and UI schemas into modular, abstract UI elements. Must remain host- and trigger-agnostic; host-specific presentation differences between Google Drive, Gmail, or web triggers are achieved by composing `UiBlock`s within trigger-specific `UiViewSchema` adapters, never by creating host-specific `UiBlock`s.
_Avoid_: Component, Widget (when referring to the composite), Module, Renderer, DriveBlock, GmailBlock

**UiView**:
A compiled, declarative view model emitted by `SchemaDrivenUi`. Flattens `UiBlock` outputs into a generic payload consumed by dumb infrastructure renderers.
_Avoid_: GoogleCard, UiCard, JsonResponse

**UiViewSchema**:
A declarative layout orchestrating which `UiBlock`s compose a `UiView`. Hard-coded within infrastructure-specific driving adapters inside `SchemaDrivenUi`.

**SourceParser**:
The domain feature responsible for inspecting a `SourceContext` to infer routing selections (`DocumentSpaceType`, `DocumentSpace`, `DocumentType`) and extract pre-populated `Document` field values according to `DocumentParseSchema`.
_Avoid_: PrePopulator, ContextExtractor, FieldExtractor

**AliasDictionary**:
A shared, option-source-scoped mapping of canonical `LookupField` option keys to alternate recognition phrases and email domains, referenced from the `Manifest` to resolve external entities across `DocumentType`s without polluting `DocumentSchema`.
_Avoid_: MatchList, SynonymMap, LookupMap

**LookupOptions**:
The domain feature responsible for resolving, validating, and enriching `LookupField` option tuples and deriving `LinkedField` values across static `DocumentSchema` lists, `DocumentLog`, and storage providers.
_Avoid_: DynamicOptions, OptionService, OptionsRegistry

**OptionSource**:
A storage-agnostic declaration inside `DocumentSchema` defining a dynamic option provider (`document_log` or `google_drive`) and its expected tuple properties.
_Avoid_: DynamicConfig, OptionProviderConfig

**OptionBinding**:
A storage-specific declaration inside `DocumentLogSchema` mapping an `OptionSource` key to a spreadsheet tab, Named Range, optional companion `validationRangeName`, sentinel `endMarker`, header-to-property column map, and optional RFC 4180 CSV `aliasesColumn`.
_Avoid_: SheetOptionConfig, OptionTableConfig
